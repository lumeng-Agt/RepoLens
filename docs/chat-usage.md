# 聊天与源码联动

可以直接提问，不必先选文件。“仅对话”不附源码；“自动参考仓库”会在本地查找相关内容，发送范围可随时查看。

目录里没有可索引的源码时，也可以直接聊天。讲解文件和生成阅读路线仍需要源码。

- 输入 `@` 搜索已索引文件、目录或符号。选择符号会附上定义行范围；目录先列出文件，超过十二个时需改为逐个选择。
- 输入 `/ask`、`/explain`、`/route`、`/investigate` 切换任务，`/new` 新建对话。这些动作不会调用模型。
- Enter 发送或选择菜单项，Shift＋Enter 换行；中文选字时不会触发发送。
- 在源码中点击行号，再 Shift 点击结束行，或拖选代码。“加入聊天”和“解释这段代码”只准备附件与草稿，点击发送才交给模型。“添加笔记”打开现有笔记编辑区。
- 路线或调查结果可以通过“调整这份结果”继续修改。旧结果保留；生成的新结果仍须核对。应用到原调查时会检查并发修改，并重置人工核对标记。
- 图谱查询中的“在聊天中分析”会填入静态关系和文件。回答菜单可将相关文件高亮到图谱；文件依赖不代表实际函数调用。
- “让 AI 帮忙找文件”先展示目录与符号摘要。点击发送摘要会调用一次模型；推荐的文件加入附件后，需要再次发送才会用于回答。不会自动连续提问。

模型设置支持 OpenAI 兼容接口、DeepSeek、Ollama 和 LM Studio 预设。预设不自动保存或联网。“获取模型列表”与“发送固定文字测试模型”是两个独立操作，测试不发送仓库信息。免密模式仅支持本机回环地址。Anthropic 原生协议需要另行适配，不能直接作为兼容端点使用。

草稿读取或保存失败时会显示提示。可以继续输入，再点击“重试草稿保存”；恢复时会保留本页新输入的内容。
